# AutoUpdate 

AutoUpdate 是一个为 Minecraft 1.20.1 设计的 Fabric 模组，它允许根据提供的模组列表自动判断是否需要更新模组。通过这个模组，服务器所有者或整合包制作者可以轻松分发更新的模组列表，客户端可以使用这些列表自动同步他们的模组。

## 使用说明

### 模组主界面选项

1. **检查更新**: 比较本地模组与远程模组列表
2. **导出模组列表**: 创建包含当前已安装模组的 JSON 文件

### 模组更新流程

1. **检查更新**: 点击主界面的"检查更新"按钮
2. **选择模组**: 在模组选择界面中，可以：
   - 点击模组条目切换选择状态
   - 使用"全选"/"取消全选"按钮批量操作
   - 查看每个模组的名称、版本和ID信息
   - **自适应布局**: 窗口大小调整时自动重新布局，保持选择状态
3. **执行更新**: 点击"更新选中的模组"按钮开始下载
4. **查看结果**: 更新完成后显示成功/失败结果，提供两个选项：
   - **返回到主界面**: 继续游戏
   - **退出游戏**: 直接关闭游戏，防止忘记重启

### 自动下载模式

如果配置了自动下载缺失模组，系统会自动下载本地缺失的模组，无需手动选择。

### 导出模组列表

要导出当前模组列表：
1. 在主界面点击"从本地生成模组列表"
2. 输入模组列表的版本
3. 点击"导出"
4. 模组列表将以 JSON 文件形式保存在版本目录下的`/autoupdate/`

## 配置选项

模组会在版本目录下`/autoupdate/config.json`创建配置文件，包含以下选项：

- `mod_list_url`: 远程模组列表 JSON 文件的 URL
- `replace_realms_button`: 是否替换 Realms 按钮（默认：false，即为在游戏主界面添加`U`字按钮）
- `auto_download_missing_mod`: 是否自动下载缺失的模组（默认：false）

## 构建方法

使用标准的 Fabric 模组构建流程：

```bash
./gradlew build
```

构建完成后，模组文件将生成在 `build/libs/` 目录中。
